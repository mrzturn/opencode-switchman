LIFECYCLE HOOKS / 四个钩子

钩入 opencode 生命周期的每一次心跳

四个钩子覆盖「启动注入 → 派发拦截 → 失败记账 → 每轮提示注入」全链路。

config

启动注入

opencode 启动即注入全量壳矩阵到 cfg.agent，同步完成三池凭证收集（auth 只读、零另存）。

tool.execute.before

派发拦截

task 工具执行前做六闸确定性校验，deny 时附原因＋改派候选，主模型按链无缝改派。

event

失败记账

执行失败写入 failures.log，600s 窗内 ≥2 败自动触发熔断 600s，约 10 分钟自愈恢复。

system.transform

每轮注入

每轮 LLM 请求注入调度员规程＋四行横幅，路由 / 水位 / 限制对调度员实时可见。

⚡

fail-open 铁律：任何钩子异常只写 stderr 绝不阻塞主流程；配额未知不硬拦，熔断器与探针互为兜底——插件永不成为单点故障。

DeepSeek 按量池恒居链尾兜底，自动路由绝不选它；同档全不可用则触发终端失败协议：显式告知＋两个可选项，禁静默降质。

PROTOCOL / ROUTE_META 协议

一行协议，六键六值逐字段校验

DELEGATION_V1 · embedded
# 委派 prompt 内嵌单行协议（示例）
ROUTE_META {
  "lane":            "main",      // 六档之一
  "role":           "programmer", // 14 角色之一
  "producer_family": "glm",      // 真实模型族
  "capability":      "rw",         // rw | ro
  "modality":        "text",       // text | image
  "source":          "auto"        // auto | user
}
  • 协议闸逐字段校验——缺失或非法即 deny，报错附正确样例，主模型照抄即修复。
  • producer_family 硬约束——copilot / glm 是池不是族；复审时与壳 family 比对，落实异族审计。
  • 语义联动——lane=review 强制 ro 壳、modality=image 强制视觉壳、source=auto 禁选付费兜底。
  • 结构化委派——DELEGATION_V1 模板随包内置，委派 prompt 自包含、可缓存、可校验。
