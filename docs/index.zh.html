LIFECYCLE HOOKS / 四个钩子

钩入 opencode 生命周期的每一次心跳

四个钩子覆盖「启动注入 → 派发拦截 → 失败分类记账 → 每轮提示注入」全链路。

config

启动注入

opencode 启动即注入全量壳矩阵到 cfg.agent，同步完成全供应商凭证收集（auth 只读、零另存）。

tool.execute.before

派发拦截

task 工具执行前做六闸确定性校验，deny 时附原因＋改派候选，主模型按链无缝改派。

event

失败分类

归一 rate_limit / quota / auth / not_found / server / network / unknown，触发 600s 熔断，并对实调失败做 10–30 分钟隔离。

system.transform

每轮注入

每轮 LLM 请求注入调度员规程＋四行横幅；每次重建都把评分候选写入 routing-decisions.jsonl。

⚡

fail-open 铁律：任何钩子异常只写 stderr 绝不阻塞主流程；配额未知不硬拦，熔断器与探针互为兜底——插件永不成为单点故障。

SIX GATES / 六闸拦截

任一命中即 deny，并附改派候选

主模型派发子代理时，插件在 task 工具执行前做确定性校验——顺序即优先级。

01
注册表闸
壳未启用 / 未探测
deny → 禁派未注册面
02
探针 / 下线闸
组合 down 或模型 retired
deny → 拦不可用或已消失模型
03
熔断 / 隔离闸
600s 熔断或 10–30min 实调隔离
deny → 自动恢复且不污染全池
04
池耗尽闸
配额判定必失败
deny → 附人读原因（GLM 100% / 积分耗尽 / DS 欠费）
05
协议闸
ROUTE_META 缺失 / 非法
deny → 附样例与合法值表，自动纠偏
06
语义闸
同族复审 / rw→ro / 图像→非视觉壳
deny → 复审须异族视角 等语义约束
SCORING ENGINE / 自动化决策

选链不靠拍脑袋，靠显式加权评分

候选链由策展能力分与六个系数实时算出——主模型照链首派发，评分过程留痕可查。

🎯

能力层级不可逆S/A/B/C

策展 base 分按 exact → 前缀 → family → global fallback 命中。低档永远压不过高档，不因水位或成本反超。

📈

六因子系数weighted

分数 = base × effortFit × health × water × costBias × peak。探针 429 仅置 strained 降权，不再整链跳到其他厂商。

🧬

水位、成本、高峰有边界bounded

两类额度窗口取最吃紧者；Copilot 富余临期可反向提权；GLM 高峰仅同档 ×0.93 让位，不跨能力级出局。

🧾

决策可追溯jsonl

每次横幅重建都会把候选与因子分写入 200 行 routing-decisions.jsonl 环形日志；immediate 紧急档仍按探针延迟排序。

PROTOCOL / ROUTE_META 协议

一行协议，六键六值逐字段校验

DELEGATION_V1 · embedded
# 委派 prompt 内嵌单行协议（示例）
ROUTE_META {
  "lane":            "main",      // 六档之一
  "role":           "programmer", // 14 角色之一
  "producer_family": "glm",      // 真实模型族
  "capability":      "rw",         // rw | ro
  "modality":        "text",       // text | image
  "source":          "auto"        // auto | user
}
  • 协议闸逐字段校验——缺失或非法即 deny，报错附正确样例，主模型照抄即修复。
  • producer_family 硬约束——copilot / glm 是池不是族；复审时与壳 family 比对，落实异族审计。
  • 语义联动——lane=review 强制 ro 壳、modality=image 强制视觉壳、source=auto 禁选付费兜底。
  • 结构化委派——DELEGATION_V1 模板随包内置，委派 prompt 自包含、可缓存、可校验。
LIVE BANNER / 四行横幅

调度依据，每轮实时可见

system.transform 钩子每轮注入系统提示——调度员永远在最新事实之上做决策。

[路由]
economy: glm-53f-low→ds-v4fv-off | mechanical: glm-53f-high→ds-v4fv-off | main: ds-v4p-high | hard: ds-v4p-max …
[水位]
GLM 5h窗 23% 周 7% (09-04 10:00刷新) | Copilot 积分不限量 已用3885 | 建议: 攻坚改glm、积分留给关键主力
[限制]
down: 无 | retired: 0 模型已下线 | reviewer 须异族 (producer family ≠ 壳 family) | DeepSeek 仅链尾兜底
[更新]
发现新版本 → 执行 /switchman-update 或 /switchman-ignore；local 模式只提示手动更新

横幅即「调度依据」——路由、水位、限制、更新四行都可逐行解析，主模型无需记忆任何静态配置。
